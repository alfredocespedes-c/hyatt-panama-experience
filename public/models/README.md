# Future 3D assets

The shipped experience uses procedural React Three Fiber geometry only.

To replace the conceptual hotel model later, place an approved, optimized file at:

`public/models/hotel-concept.glb`

Keep it under roughly 2 MB for mobile, use meshopt/Draco compression when the tested loader supports it, bake nonessential lighting, and preserve the current model origin and scale. Record the source, rights holder, approver, and export settings here before shipping. Do not add scanned or extracted third-party building models.
